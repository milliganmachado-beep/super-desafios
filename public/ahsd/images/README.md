# Imagens da visual novel AHSD

Coloque aqui as imagens das cenas usando apenas o nome-base da cena/subcena.

## Cenas principais

- `01.webp`, `01.png`, `01.jpg` ou `01.jpeg`
- `02.webp`, `02.png`, `02.jpg` ou `02.jpeg`
- ...
- `30.webp`, `30.png`, `30.jpg` ou `30.jpeg`

## Subcenas

As quatro consequências de cada cena usam as letras `a`, `b`, `c` e `d`, na mesma ordem das quatro opções:

- `01a.webp` / `.png` / `.jpg` / `.jpeg`
- `01b.webp` / `.png` / `.jpg` / `.jpeg`
- `01c.webp` / `.png` / `.jpg` / `.jpeg`
- `01d.webp` / `.png` / `.jpg` / `.jpeg`
- ...
- `29a` a `29d`

O jogo procura automaticamente nesta ordem: `.webp`, `.png`, `.jpg`, `.jpeg`.

Se a imagem tiver proporção diferente da área visual, ela é recortada pelo centro (`object-fit: cover`) em vez de ser distorcida.
